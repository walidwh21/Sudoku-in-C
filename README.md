# Sudoku-in-C

Sudoku game developed in C in 2021 as a practical project to apply programming fundamentals and data structures

### About the Project

This project implements the classic Sudoku puzzle game using the C programming language. It was developed as a learning project to strengthen my understanding of C and put theoretical concepts into practice through a real game

The main objective was to apply programming logic, problem-solving techniques, and data structures while developing a playable Sudoku game

### Built With

- Language: C

- IDE / Project: Code::Blocks

### Project Structure

- main.c — Main entry point of the program

- sudoku-functions.c — Sudoku game functions and logic

- sudoku.h — Header file containing declarations

- Sudoku.cbp — Code::Blocks project file

### Prerequisites

- C compiler, such as GCC.

- Code::Blocks or another C development environment.

### Run the Project

Clone the repository:

```bash
git clone https://github.com/walidwh21/Sudoku-in-C.git
```

Navigate to the project directory:

```bash
cd Sudoku-in-C
```

Compile the source files using GCC:

```bash
gcc main.c sudoku-functions.c -o sudoku
```

Run the game:

Windows:

```bash
.\sudoku.exe
```

Linux / macOS:

```bash
./sudoku
```
